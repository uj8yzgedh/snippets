# Contributing

Thanks for wanting to add a snippet!

## How to add

- Place each snippet in its own file under `snippets/<language>/`.
- Use a descriptive filename: `react-use-state.md`, `node-stream-pipeline.js`.
- Include a short comment or intro explaining what the snippet does.
- Keep snippets focused: one idea per file.

## Format

Prefer runnable code. If a snippet needs context, add it as a comment or a small README in the same folder.

## Checklist

- [ ] File is in the right language folder
- [ ] Filename is descriptive
- [ ] Code is tested/verified
- [ ] No sensitive data
